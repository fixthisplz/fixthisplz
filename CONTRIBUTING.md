# Contributing to FixThisPlz

Thanks for your interest! FixThisPlz is at the very beginning: there is no code here yet, only a [vision](README.md).
That makes this the best moment to shape it.

By taking part, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Right now: discuss the vision

The most useful contributions today are opinions:

- **Does the problem resonate with you?** Tell us how you collect bug reports from clients or users today.
- **Is something missing, or out of scope?** Challenge the [non-goals](README.md#non-goals) and the [roadmap](README.md#roadmap).
- **Which integration or framework would you need first?**

Start a thread in [Discussions](https://github.com/fixthisplz/fixthisplz/discussions). Disagreement is welcome.

## Soon: code

Once the first packages land (see the roadmap), this guide will cover:

- setting up the monorepo locally
- running the tests
- writing an integration or an adapter (the easiest way to make a first contribution)
- translating the widget

Issues labelled `good first issue` will be the place to start.

## Ground rules

- **Small and focused beats big and broad.** One pull request = one change.
- **Tests come with the code.** A bug fix includes a test that fails without it.
- **Keep it simple.** If a feature needs a page of configuration, it probably belongs in the non-goals.
- **English** for code, issues and docs, so everyone can join. Translations of the UI are very welcome.

## Security

Please do **not** open a public issue for a security problem. See [SECURITY.md](SECURITY.md).
